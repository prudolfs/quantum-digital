# Project Portfolio

## 1. Finance Document Assistant | 2026

An AI assistant that extracts and validates receipt and invoice data, answers questions with source references, and generates totals, tables, and charts. Built with React, TanStack Start, and Convex.

[GitHub](https://github.com/prudolfs/fin-doc-assistant)

## 2. Service Operations Copilot | 2026

A mobile and web app for booking, tracking, and coordinating service jobs, with real-time chat, AI summaries, voice input, and reply suggestions. Built with React Native, TanStack Start, and Convex.

[GitHub](https://github.com/prudolfs/service-operations-copilot)

## 3. Robotics Lab | 2026

A browser-based robotics platform with a robot simulator, 3D drone mission planner, and visual SLAM explorer. Built with TypeScript, React, and Three.js.

[GitHub](https://github.com/prudolfs/robotics-lab)

## 4. QD Editor | 2026

A visual editor for Phaser-based mobile games, bringing scene composition, asset processing, animations, and game flow into one Electron and React app.

[GitHub](https://github.com/prudolfs/qd-editor)

## 5. Kanban Board | 2025

A lightweight Trello alternative with drag-and-drop tasks, real-time updates, and team collaboration. Built with Next.js, React, and Convex.

[GitHub](https://github.com/prudolfs/kanban-board)

## 6. Custom E-Shop Admin Panel | 2020

A custom Shopify-style back office for an online clothing store, with product, inventory, and order management plus Stripe payments. Built with React, Express, and MongoDB.

[GitHub](https://github.com/prudolfs/custom-e-shop-admin-panel)

## 7. TimerApp | 2016

A Toggl-inspired time-tracking app built as a playground for React frameworks and tools.

[GitHub](https://github.com/prudolfs/timerapp)
