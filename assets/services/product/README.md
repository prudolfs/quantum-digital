# Product development illustration

The original conceptual product layers are generated by `scripts/render-services.py`. The scene and high-resolution render are source assets for the Product development service page; they do not depict a shipped client application.

## Rebuild

From the repository root:

```sh
blender --background --python scripts/render-services.py -- --theme product --master
node scripts/prepare-service-images.mjs product
```

The Blender command retains `product-hero.blend` and a lossless 2860 × 1560 `product-hero.png` here. It uses the original orthographic view, product/interface layers, navy studio, and blue accents. Running it for this theme leaves the other homepage illustrations unchanged. The original command without arguments still rebuilds all four 880 × 480 homepage JPEGs.

The image preparation command produces 1400 × 764 desktop and 768 × 419 mobile WebPs under `public/services/product/`. Both show the whole composition at the original aspect ratio; their declared dimensions reserve layout space. `images.json` records sizes. The script enforces 80 KB desktop and 35 KB mobile limits.

Only optimized WebPs are served to visitors. These source files are retained outside `public/`. The page identifies its image as a conceptual illustration and uses a static hero in this phase. A lightweight export of the actual scene geometry and viewer integration belongs to Phase 3; no service GLB is shipped yet.
